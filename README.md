# The human curve

[Open the public viewer](https://pablorom2004.github.io/spire-human-curve/)

Public human run records for **Slay the Spire I (A20 Heart)** and **Slay the Spire II (A10)**, compared separately with Epoch AI model results. Snapshot: 13 November 2026.

- StS1: 75 public Stats Tracker accounts, 68,702 runs; separate 565-run streamer archive and three SpirePilot profiles.
- StS2: 316 identified replay accounts in the broader comparison; separate aggregate view of 439,515 uploaded A10 runs.
- Account history (default: 5+ runs) and abandonment filters, confidence intervals, sources and downloadable data.

These are self-selected public uploads. Percentiles describe recorded accounts in the selected sample, not all players or latent skill. Sources may overlap and are kept separate. Read [the methods](METHODS.txt) for inclusion criteria and provenance.

[Download the offline viewer and data](spire-viewer.zip). No server or dependencies are required; open `index.html` locally for the chart.
