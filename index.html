Data & caveats

Each account has equal weight. The curve smooths observed records; it is not a normal fit to human ability. Character choice, short histories and different seeds limit comparisons. Epoch’s default leaderboard averages both games; this viewer shows each game separately. One-run histories are especially noisy.

Stats Tracker: one website-default, latest public profile per account, with all available history. Uploads are unvalidated, and human character mixes and historical game builds vary. Equal-character profiles are unavailable in this extract. The streamer archive is a separate selected sample; abandonment flags and complete player attribution are missing, so no player percentiles are computed. Sources may overlap and are never added together.

StS2 “All runs” includes every solo standard A10 record on the original five characters in the export, including unattributed records and obvious modded items. Unlinked runs cannot be grouped into people. Bulk exports lack usable account IDs; public replay listings restore attribution where run hashes match. “5+ per character” weights all five characters equally.
